# Contributing to JeevaRaksha

Thank you for helping improve JeevaRaksha!

## Rules for Contributors
1. **Never commit real patient records, personal phone numbers, Aadhaar/PAN numbers, passwords, or API keys.**
2. **Never fabricate hospital data or medical instructions.** All hospital changes must cite an authoritative public source and verification date. All first-aid changes require clinician review before removing educational-only notices.
3. **Run automated tests** (`npm run test:unit` and `npm run test:e2e`) before opening a Pull Request.
4. **Respect contributor IP:** Licensing is currently pending explicit written sign-off from all original contributors (see `LICENSE-PENDING.md`).
